# MemoDolmaeng

평소에는 화면에서 사라져 있다가 엣지에 포인터를 대면 메모 제목만 꺼내 보여주는 로컬 macOS 메모 앱입니다.

## 제품 흐름

- 활성 메모 인덱스는 기본적으로 오른쪽 중앙의 촘촘한 한 그룹에 붙습니다.
- 왼쪽, 오른쪽 또는 메뉴 막대 바로 아래 상단 엣지에 포인터를 0.18초 대면 해당 엣지의 인덱스만 나타납니다.
- 포인터가 핫존과 인덱스를 벗어나면 기본 0.35초 뒤 인덱스가 다시 숨습니다.
- 인덱스 묶음 옆의 `+`를 누르면 그 엣지에 새 메모가 ICE로 열립니다.
- 좌우 인덱스도 세로 글자가 아닌 26px 높이의 가로형 제목 탭으로 나타납니다.
- 인덱스에 포인터를 올리면 포커스를 뺏지 않는 `PEEK`, 클릭하면 편집 가능한 `ICE`로 열립니다. 같은 ICE 인덱스를 다시 클릭하면 접힙니다.
- 선택 인덱스와 본문은 하나의 네이티브 패널 표면을 이룹니다. 인덱스 전체 크기에서 본문으로 마스크가 확장되고, 접을 때는 같은 경로를 역으로 돌아갑니다.
- PEEK에서도 TopBar는 항상 보이며, 제목줄·본문·도구를 클릭하면 즉시 ICE로 전환되어 편집 포커스가 활성화됩니다.
- `PEEK`는 포인터가 인덱스와 메모를 모두 벗어나면 접히고, `ICE`는 인덱스가 숨더라도 유지됩니다.
- 여러 메모를 동시에 ICE로 고정할 수 있습니다. 다른 메모를 열어도 기존 ICE와 저장 데이터는 유지되고, `Esc`나 `Cmd+W`는 현재 포커스된 패널 하나만 접습니다.
- 메모 패널 가장자리를 드래그하면 메모별 크기를 조절할 수 있고, 저장된 크기는 다시 열거나 앱을 재실행해도 유지됩니다.
- `Esc`와 `Cmd+W`는 삭제가 아니라 접기입니다.
- 앱은 Dock 없이 메뉴 막대에 상주하며 모든 Space와 전체 화면 앱 위에서 접근할 수 있습니다.

## 그룹과 배치

- 활성 메모는 최대 10개, 보관 메모는 무제한입니다.
- 하나의 그룹 안에서는 간격 0px로 붙고, 서로 다른 그룹은 최소 6px를 둡니다.
- 인덱스를 기존 그룹 밖으로 끌면 단독 그룹이 되고, 다른 그룹 12px 안에 놓으면 해당 순서로 합쳐집니다.
- 드래그 중에는 왼쪽, 오른쪽, 상단 드롭 영역이 나타납니다.
- 인덱스를 드래그하면 화면 아래 중앙에 삭제 영역이 나타납니다. 그곳에 놓고 확인하면 본문과 첨부파일을 영구 삭제합니다.
- 상단 인덱스는 `NSScreen.visibleFrame.maxY` 아래에 붙고 메모는 아래 방향으로 열립니다.
- 작은 화면에서는 제목 원본과 툴팁은 유지한 채 인덱스 길이만 자동 압축합니다.
- 제목은 본문과 분리된 전용 입력줄에 최대 40자까지 저장됩니다. 기존 6글자 제목은 본문 첫 줄과 자연스럽게 이어질 때만 전체 표시 제목을 복원하고, 직접 입력한 제목은 그대로 유지합니다.
- 오래된 수동 그룹의 위치를 먼저 보존하고, 새 그룹과 기본 그룹이 남은 연속 공간에 맞춰 이동하거나 압축됩니다.
- 메모별 설정의 `크기 프리셋`에서 `1:1` 또는 `3:4`를 고르면 수동 크기를 해제하고 기본 크기로 복원합니다.
- 모니터가 사라지면 포인터가 있는 화면, 그다음 주 화면으로 복구됩니다.

## 메모 생명주기

- 새 메모는 검정 단일색 대신 노랑, 파랑, 초록, 분홍, 보라, 회색 팔레트에서 무작위 색을 받습니다. 가장 최근 메모와 같은 색은 피해 연속 생성 시 구분력을 높입니다.
- 인덱스와 메모 패널에는 각각 9px, 10px 모서리 반경을 적용합니다. 패널이 열린 동안에는 연결된 인덱스의 안쪽 모서리만 평평하게 처리해 하나의 표면처럼 보이게 합니다.
- 새 메모는 빈 임시 초안으로 열리며 의미 있는 텍스트, 목록, 표, 코드 또는 이미지가 생긴 순간에만 저장됩니다.
- 빈 초안을 접으면 저장 파일에 흔적을 남기지 않습니다.
- 기존 메모를 완전히 비운 뒤 그 메모를 접거나 보관하거나 앱을 종료하면 본문과 첨부파일을 영구 삭제합니다. 다른 메모를 여는 것만으로는 기존 메모를 닫거나 삭제하지 않습니다.
- 보관은 되돌릴 수 있지만 보관함의 `삭제`는 확인 후 영구 삭제합니다. 휴지통과 자동 보관은 없습니다.
- 활성 메모 10개가 가득 차면 자동 보관하지 않고 보관함을 엽니다.

## 네이티브 편집기

편집기는 AppKit TextKit 2 기반의 `swift-markdown-engine` `0.10.0`을 정확히 고정해 사용합니다. `WKWebView`, Milkdown, Crepe와 npm 빌드 단계는 제거했습니다. Markdown 문자열은 계속 저장 원본이지만, 커서가 서식 밖에 있을 때 `#`, `**`, `~~` 같은 마커를 거의 보이지 않게 줄여 Typora에 가까운 읽기 경험을 제공합니다.

- PEEK와 ICE에서 항상 같은 자리를 유지하는 한 줄 SwiftUI 상단 툴바. 아이콘·구분선·활성 상태는 메모 글자색을 따르고, 좁은 패널에서는 툴바만 가로 스크롤됩니다.
- TopBar와 본문은 독립된 세로 영역이며, 긴 문서는 TopBar 아래에서만 스크롤됩니다.
- 글머리표, 번호 목록, 체크리스트, 인용, 제목, 구분선, GFM 표
- 굵게, 기울임, 취소선, 인라인 코드와 코드 블록
- `Cmd+B/I`, 실행 취소/다시 실행, 목록 들여쓰기와 한글 조합 입력
- 체크박스 직접 클릭, HTML이 섞인 붙여넣기의 Markdown 변환, macOS 맞춤법·Writing Tools

기본 본문 글꼴은 11pt이며 설정에서 조절할 수 있습니다. 별도 raw Markdown 모드, slash 명령, 블록 드래그 핸들, AI 기능은 제공하지 않습니다. 기존 Markdown 문자열을 임의로 정규화하지 않으므로 지원하지 않는 HTML도 저장 원문에는 남습니다.

이미지는 네이티브 이미지 버튼이나 붙여넣기로 추가합니다. Swift가 실제 이미지 여부와 20MB 제한을 확인한 뒤 `attachments/<note-id>/`로 복사하고, UUID와 단일 파일명만 허용하는 `memodolmaeng-asset://` 경로 해석기로 표시합니다.

## 단축키

- `Cmd+Shift+M`: 최근 메모 열기 또는 현재 메모 접기, 시스템 전역
- `Cmd+Shift+Up`, `Cmd+Shift+Down`: 열린 상태에서 이전 또는 다음 메모
- `Cmd+1`~`Cmd+0`: 열린 상태에서 1~10번 메모로 전환
- `Esc`, `Cmd+W`: 현재 메모 접기
- `Cmd+N`: 새 임시 메모

전역 단축키는 Carbon Hot Key API를 사용하므로 접근성 권한이 필요하지 않습니다.

## 로컬 저장과 v3 이전

```text
~/Library/Application Support/MemoDolmaeng/
├── notes.json
├── Backups/
├── attachments/<note-id>/
└── DeletionStaging/
```

```json
{
  "schemaVersion": 3,
  "notes": [],
  "edgeGroups": [],
  "defaultGroupID": "UUID"
}
```

`panelSize`는 사용자가 직접 크기를 바꾼 메모에만 저장되는 선택 필드입니다. 기존 v3 메모에는 필드가 없어도 기존 비율 프리셋으로 동일하게 열립니다.

v2를 처음 열 때 원본 바이트를 `Backups/notes-pre-edge-v3-<timestamp>.json`에 먼저 기록합니다. 내용이 있는 메모만 가져오고, 활성 메모는 기존 `handlePosition` 내림차순으로 정렬해 오른쪽 중앙 기본 그룹에 합칩니다. 백업, 변환 또는 v3 저장이 실패하면 v2 원본을 바꾸지 않고 앱 시작을 중단합니다.

첨부파일 영구 삭제는 디렉터리를 staging으로 이동한 뒤 메모 저장에 성공하면 물리 삭제합니다. 중간에 앱이 종료되면 다음 시작 때 메모 존재 여부에 따라 복구하거나 정리합니다.

## 구조

- `EdgeWorkspaceController`: 앱 상태, 초안/삭제 생명주기, 엣지 생성 컨트롤, 드래그 삭제, 단일 PEEK와 다중 ICE
- `EdgeLayoutEngine`: 세 엣지 프레임, 그룹 압축, 충돌과 삽입 순서 계산
- `EdgeHotZoneController`, `EdgeHandlePanelController`, `EdgeControlPanelController`: 숨김 핫존, 인덱스와 엣지 `+` 패널
- `DeleteDropZoneController`: 인덱스를 끌 때만 나타나는 영구 삭제 드롭 영역
- `MemoPanelController`, `UnifiedEdgeMemoSurfaceView`: 메모별로 독립된 인덱스-본문 네이티브 표면
- `MarkdownEditorView`: TextKit 2 편집기, 네이티브 TopBar와 Markdown 명령 버스
- `NoteStore`: v3 저장, v1/v2 백업 이전, 그룹 불변식과 활성 10개 제한
- `AttachmentService`, `MemoAssetSchemeHandler`: 이미지 복사, staged 삭제, 안전한 로딩
- `LibraryView`, `PreferencesView`: 검색 보관함과 공통/메모별 설정
